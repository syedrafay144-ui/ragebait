    The grammar

    NounsThe things on the page: heading subheading paragraph button link image box list item line
    AdjectivesHow things look: colours (red blue green orange purple pink yellow teal gray black white) and big huge small bold italic centered rounded wide padded glowing dark light underlined spaced
    Articlesa / an introduce something new (and must agree: an before a vowel). the refers to something that already exists.
    Proper nounsNames start with a capital: called Tally. Use the Tally later.
    VerbsCreate/Make/Add/Place/Build a … · Make the X … · Change the X to say "…" · Show Count in the X · Remember a number called N as 0 · Add 1 to N · Subtract 1 from N · Set N to 5
    Prepositionsinside the Box puts a thing in another. going to "url", showing "image", saying "text". You add to, you subtract from.
    AdverbsEnd a sentence with slowly gently quickly (fade in) or loudly (shout).
    ClausesWhen the X is clicked, … · If N is more than 3, … · then joins actions.
    PunctuationCapital letter to start, full stop to end. An exclamation mark shouts (bold, capitals). A question mark is an error: Ragebait gives orders, not questions.
